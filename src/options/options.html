Memory budget

Each check puts up to two eligible tabs to sleep until memory use falls below the sleep threshold.

Optional capabilities

Local Companion

Measures Chrome’s memory use and enables Folder Sync. Run this command to install the companion on your computer.

Weighted Eviction

Uses page access to measure memory, page elements and media when choosing which tabs to put to sleep.

Folder Sync

Choose a local folder for backups. To share snapshots and settings across devices, use a folder your cloud storage already syncs.

Session recovery

Restore windows, tab order, groups, and pinned or kept tabs. Your sync folder keeps 20 recent snapshots, 24 hourly, 30 daily, and all manual snapshots. Up to 5 recent snapshots stay on this device.
