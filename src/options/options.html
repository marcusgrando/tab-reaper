Optional Capabilities

Exact Chrome RAM (Optional Native Host)

Optional. Reads exact Chrome process memory on macOS, Linux, and Windows instead of OS-wide RAM. No build tools required — copy and run once, then click Enable and Test.

Weighted Eviction (JS Heap + DOM Sampling)

Samples candidate tabs on demand to discard heavier pages first. Zero content scripts at startup.

Session Recovery (Local Snapshots)

Automatically saves up to 5 local session snapshots (every 5 min when tabs change) including pinned, kept, and tab groups. Stored locally without touching Chrome Sync.
